# deps/forks-documented/rust

Forked or patched dependencies are documented

## Requirement

A git source in Cargo.toml (including `[patch]` entries) is documented in FORKS.md or a Forks section, or carries a ` #` comment on the line.

## Why

A fork without a note outlives the reason for it; the next upgrade either drops the fix or keeps the fork forever.

## Applies when

```cel
grep("Cargo.toml", r'\bgit\s*=\s*"').size() > 0
```

## Check

For each `item` in:

```cel
grep("Cargo.toml", r'\bgit\s*=\s*"').filter(l, !l.text.matches(r'\s#'))
```

```cel
exists("FORKS.md") || exists("docs/FORKS.md") || exists("docs/forks.md") || grep("README.md", r'^#+ .*\b(forks?|vendored|patched|patches)\b').size() > 0 || grep("docs/**/*.md", r'^#+ .*\b(forks?|vendored|patched|patches)\b').size() > 0
```

This implementation has no fix of its own: see [deps/forks-documented](deps--forks-documented.md#fix).
