Toolchain version is pinned

## Requirement

`.ruby-version` names a version, the Gemfile declares `ruby "x.y.z"`, or `.tool-versions`/mise or `devbox.json` names ruby with a version. In `devbox.json` the package needs a version (`ruby@3.4`, `ruby_3_4`); `@latest` does not count.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

```cel
     file(d + n) && scan(d + n, r'^\s*"?(ruby)"?\s*=\s*[^#\n]*\d').size() > 0))
|| ["", "../", "../../", "../../../"].exists(d, file(d + "devbox.json") && text(d + "devbox.json").matches(r'"(ruby)(@v?\d|"\s*:\s*("v?\d|\{[^}]*"version"\s*:\s*"v?\d))|"(ruby_\d+_\d+)(@[^"]*)?"'))
```

## Fix

Write the Ruby version to .ruby-version.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

A finding of this rule points at `.ruby-version`.
