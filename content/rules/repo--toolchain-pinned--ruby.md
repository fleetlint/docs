## Requirement

`.ruby-version` names a version, the Gemfile declares `ruby "x.y.z"`, or `.tool-versions`/mise names ruby with a version.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
scan(".ruby-version", r'^\s*(ruby-)?\d').size() > 0 || scan("Gemfile", r'^\s*ruby\s+["\x27]\d').size() > 0 || scan(".tool-versions", r'^\s*(ruby)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(ruby)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Write the Ruby version to .ruby-version.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.
