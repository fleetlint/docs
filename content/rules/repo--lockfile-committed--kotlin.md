## Requirement

A Gradle build tracks dependency lock state (gradle.lockfile from `dependencyLocking`) or dependency verification metadata (gradle/verification-metadata.xml, also at the root of a multi-project build).

## Why

Builds are reproducible only when dependency versions are pinned in git.

## Check

```cel
tracked().exists(f, f.matches(r'(^|/)((settings|buildscript)-)?gradle\.lockfile$') || f == "gradle/verification-metadata.xml") || ["../", "../../", "../../../"].exists(d, file(d + "gradle/verification-metadata.xml"))
```

## Fix

Enable `dependencyLocking { lockAllConfigurations() }` and run `./gradlew dependencies --write-locks`, or write verification metadata with `./gradlew --write-verification-metadata sha256 help`; commit the result.

Agent instruction: Run the package manager to produce the lockfile, remove any .gitignore entry for it, and commit it.

See: <https://fleetlint.org/baseline/#dependencies>, <https://fleetlint.org/stacks/#kotlin-jvm--android>
