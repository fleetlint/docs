## Requirement

A task-runner recipe or a CI step runs madewithlove/license-checker (`license-checker check` against .allowed-licenses), or a stack-neutral license checker. `composer licenses` alone only lists licenses and does not count.

## Why

A dependency under an incompatible license is found cheaply before it is merged and expensively after a release.

## Fix

Add madewithlove/license-checker, generate .allowed-licenses and run `vendor/bin/license-checker check` in the `audit` target.

Agent instruction: Add the stack's license checker to the audit target with an allowlist compatible with the repository's own license; report dependencies outside it instead of widening the list.
