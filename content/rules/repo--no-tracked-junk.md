# repo/no-tracked-junk

No editor, OS or backup files are tracked

## Requirement

Files such as .DS_Store, Thumbs.db, *.bak, *.orig, *.swp, *.log, nohup.out, Python bytecode, dependency directories and personal IDE state (.idea/workspace.xml) are never committed. Log files and dependency directories under testdata/, fixtures/, __tests__/ and test directories are test inputs and are not findings; a shared .vscode/settings.json is project configuration and is not read.

## Why

They are noise at best and leak local paths or data at worst.

## Check

For each `item` in:

```cel
tracked().filter(p, p.matches(r'(^|/)(\.DS_Store|Thumbs\.db|desktop\.ini|nohup\.out)$|\.(bak|orig|rej|swp|swo|log|pyc)$|~$|(^|/)(__pycache__|node_modules|\.venv|venv)/|(^|/)\.idea/workspace\.xml$')
  && !((p.endsWith(".log") || p.contains("node_modules/")) && p.matches(r'(^|/)(testdata|fixtures?|__fixtures__|__tests__|test|tests|spec)/')))
```

```cel
false
```

## Fix

git rm --cached the listed files and add their patterns to .gitignore.

Agent instruction: Untrack the listed junk files with git rm --cached, add matching patterns to .gitignore, commit as chore.
