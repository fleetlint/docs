# deps/unused-check/hugo

[deps/unused-check](deps--unused-check.md) does not apply to hugo: nothing is checked for it.

## Why it does not apply

A Hugo site has no dependency manager of its own. Hugo modules (go.mod) are not checked: a site's go.mod does not make it a Go project unless Go sources sit next to it. npm tooling in package.json is checked as Node.
