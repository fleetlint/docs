# repo/toolchain-pinned/go

Toolchain version is pinned

## Requirement

go.mod has a `toolchain` directive or a full `go 1.x.y` version, or `.tool-versions`/mise names go with a version.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
scan("go.mod", r'^(toolchain go\d+\.\d+|go \d+\.\d+\.\d+)').size() > 0 || scan(".tool-versions", r'^\s*(go|golang)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(go|golang)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Set `go 1.x.y` (or a `toolchain go1.x.y` line) in go.mod.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.
