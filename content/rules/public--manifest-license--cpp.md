# public/manifest-license/cpp

Package manifest declares the license

## Requirement

vcpkg.json sets `license` and conanfile.py sets `license`, where they exist; plain CMake projects have no license field and are not checked.

## Why

Registries, SBOM tools and license checkers read the manifest, not the LICENSE file.

## Capability applies when

```cel
repo.public
```

## Check

```cel
(!file("vcpkg.json") || (json("vcpkg.json") != null && has(json("vcpkg.json").license))) && (!file("conanfile.py") || text("conanfile.py").matches(r'(?m)^\s*license\s*='))
```

## Fix

Add `"license": "<SPDX id>"` to vcpkg.json or `license = "<SPDX id>"` to the conanfile.

Agent instruction: Set the manifest's license field to the SPDX identifier matching the LICENSE file; ask if the LICENSE text is not a recognised license.
