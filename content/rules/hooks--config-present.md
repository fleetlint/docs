## Requirement

The repository declares git hooks that run on every commit: a `.pre-commit-config.yaml` (pre-commit or prek) or a lefthook configuration (`lefthook.yml`, `.lefthook.yml` and their YAML, TOML and JSON variants).

## Why

Hooks are the only gate that runs before code reaches the remote; everything else is after the fact.


## Fix

Run `fleetlint fix --apply` to add .pre-commit-config.yaml for the stack, then `prek install` (the file uses prek's builtin hooks; pre-commit cannot run it).

Agent instruction: Create .pre-commit-config.yaml from the shared template plus the stack block, run `prek update` and `prek install`.
