# release/reproducible-build/helm-chart

Release builds are reproducible

Implements [release/reproducible-build](release--reproducible-build.md) for the `helm-chart` artifact: it runs when the release publishes one (see [artifacts](capabilities.md#artifacts)).

## Requirement

`helm package` keeps the file timestamps of the checkout; the chart archive of a commit differs only in those, and the registry stores it by digest. Not checked.

## Why

When anyone can rebuild a release bit for bit from the tag, a tampered artifact or a compromised build machine shows up as a mismatch.

## Fix

Set the stack's reproducibility options in the release build (see https://reproducible-builds.org/docs/) and export SOURCE_DATE_EPOCH from the commit time.

Agent instruction: Add the stack's reproducibility settings to the release build and derive SOURCE_DATE_EPOCH from `git log -1 --format=%ct`; do not change what is built.
