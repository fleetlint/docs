# repo/toolchain-pinned/node

Toolchain version is pinned

## Requirement

`.nvmrc` or `.node-version` names a version (not `lts/*` or `node`), package.json has a `volta` pin, or `.tool-versions`/mise names node with a version. `engines.node` is a range and `packageManager` pins the package manager, not Node; neither counts.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
scan(".nvmrc", r'^\s*v?\d').size() > 0 || scan(".node-version", r'^\s*v?\d').size() > 0 || grep("package.json", r'"volta"\s*:').size() > 0 || scan(".tool-versions", r'^\s*(node|nodejs)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(node|nodejs)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Write the Node version you use to .nvmrc (e.g. `node --version > .nvmrc`).

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

See: <https://fleetlint.org/baseline/#hygiene>, <https://fleetlint.org/stacks/>, <https://fleetlint.org/stacks/#nodejs--typescript>
