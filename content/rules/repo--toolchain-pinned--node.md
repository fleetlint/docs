Toolchain version is pinned

## Requirement

`.nvmrc` or `.node-version` names a version (not `lts/*` or `node`), a package.json here or in a parent directory has a `volta` pin, or `.tool-versions`/mise names node with a version. `engines.node` is a range and `packageManager` pins the package manager, not Node; neither counts.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
["", "../", "../../", "../../../"].exists(d, file(d + ".nvmrc") && scan(d + ".nvmrc", r'^\s*v?\d').size() > 0) || ["", "../", "../../", "../../../"].exists(d, file(d + ".node-version") && scan(d + ".node-version", r'^\s*v?\d').size() > 0) || ["", "../", "../../", "../../../"].exists(d, file(d + "package.json") && text(d + "package.json").matches(r'"volta"\s*:')) || ["", "../", "../../", "../../../"].exists(d, file(d + ".tool-versions") && scan(d + ".tool-versions", r'^\s*(node|nodejs)\s+\S*\d').size() > 0) || ["", "../", "../../", "../../../"].exists(d, ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(n,
     file(d + n) && scan(d + n, r'^\s*"?(node|nodejs)"?\s*=\s*[^#\n]*\d').size() > 0))
```

## Fix

Write the Node version you use to .nvmrc (e.g. `node --version > .nvmrc`).

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

A finding of this rule points at `.nvmrc`.
