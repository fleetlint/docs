# repo/toolchain-pinned/flutter

Toolchain version is pinned

## Requirement

`.fvmrc` (or `.fvm/fvm_config.json`) exists, pubspec.yaml's `environment.flutter` is an exact version, or `.tool-versions`/mise names flutter with a version.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
file(".fvmrc") || file(".fvm/fvm_config.json") || scan("pubspec.yaml", r'^\s+flutter:\s*["\x27]?\d+\.\d+\.\d+["\x27]?\s*$').size() > 0 || scan(".tool-versions", r'^\s*(flutter)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(flutter)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Run `fvm use <version>` (writes .fvmrc).

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

See: <https://fleetlint.org/baseline/#hygiene>, <https://fleetlint.org/stacks/>, <https://fleetlint.org/stacks/#flutter--dart>
