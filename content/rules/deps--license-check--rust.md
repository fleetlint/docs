# deps/license-check/rust

Dependency licenses are checked against an allowlist

Implements [deps/license-check](deps--license-check.md) for rust.

## Requirement

deny.toml has a `[licenses]` allowlist and a task-runner recipe or a CI step runs `cargo deny check` including licenses (or cargo-deny-action), or a stack-neutral license checker runs.

## Why

A dependency under an incompatible license is found cheaply before it is merged and expensively after a release.

## Parameters

- `skip`: `^\s*[@+-]*\s*(\{\{[^}]*\}\}\s*|\$[({][A-Za-z_]+[)}]\s*)?(#|//|echo\b|printf\b|(sudo\s+)?(go (install|get)|cargo b?install|pipx? install|pip3 install|python3? -m pip install|uv (tool |pip )?(install|add)|(npm|pnpm|yarn|bun) (i|install|add|global add)|gem install|bundle add|brew install|dotnet tool (install|update)|composer (global )?require|apt(-get)? install|curl|wget)\b[^;&]*$)`

## Fix

Add a `[licenses]` allow list to deny.toml and run `cargo deny check licenses` in the `audit` target.

Agent instruction: Add the stack's license checker to the audit target with an allowlist compatible with the repository's own license; report dependencies outside it instead of widening the list.
