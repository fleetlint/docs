## Requirement

Every stack has a formatter, configured in the repository or run by a hook, the task runner or CI, so formatting is never a review topic.

## Why

Without one formatter every editor reformats differently and diffs fill with whitespace churn that hides the real change.

## Fix

Add the stack's formatter to the hooks and the fmt target (see https://fleetlint.org/stacks/).

Agent instruction: Add the stack's formatter to the pre-commit hooks and the fmt target; reformat the code base in a separate commit.

See: <https://fleetlint.org/baseline/#static-analysis>
