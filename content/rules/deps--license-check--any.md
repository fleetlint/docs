# deps/license-check/any

Dependency licenses are checked against an allowlist

The stack-neutral implementation of [deps/license-check](deps--license-check.md): it checks stacks without an implementation of their own and repositories where no stack is detected, and its satisfiers count for every stack.

## Requirement

A task-runner recipe or a CI step checks licenses with a stack-neutral tool: `osv-scanner --licenses=...`, trivy with the license scanner, ScanCode (`--license`), FOSSA, ORT `evaluate`, or GitHub dependency review configured with `allow-licenses`/`deny-licenses` (or a config file). Comments, `echo` lines and install-only lines do not count.

## Why

A dependency under an incompatible license is found cheaply before it is merged and expensively after a release.
