## Requirement

No file contains a merge conflict marker (`<<<<<<<` or `>>>>>>>` at the start of a line), whatever its type. Fenced code blocks in Markdown are not read.

## Why

The file does not mean what either side intended; code usually does not compile and configuration silently changes meaning.

## Check

For each `item` in:

```cel
grep("**", r'^(<{7}|>{7})( |$)')
```

```cel
false
```

## Fix

Resolve the conflict and remove the markers.

Agent instruction: Resolve the conflict using both sides' intent; ask when they contradict.
