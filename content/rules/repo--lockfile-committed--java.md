## Requirement

A Gradle build tracks dependency lock state (gradle.lockfile from `dependencyLocking`) or dependency verification metadata (gradle/verification-metadata.xml). Maven has no native lockfile, so a Maven-only build is not checked.

## Why

Builds are reproducible only when dependency versions are pinned in git.

## Applies when

```cel
file("build.gradle") || file("build.gradle.kts")
```

## Check

```cel
tracked().exists(f, f.matches(r'(^|/)((settings|buildscript)-)?gradle\.lockfile$') || f == "gradle/verification-metadata.xml")
```

## Fix

Enable `dependencyLocking { lockAllConfigurations() }` and run `./gradlew dependencies --write-locks`, or write verification metadata with `./gradlew --write-verification-metadata sha256 help`; commit the result.

Agent instruction: Run the package manager to produce the lockfile, remove any .gitignore entry for it, and commit it.
