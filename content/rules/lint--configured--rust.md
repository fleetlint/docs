## Requirement

Cargo.toml configures the compiler and clippy lints in a `[lints]` table, `[workspace.lints]`, or inherits the workspace's with `[lints] workspace = true`.

## Why

Unwrap-driven crashes are the Rust equivalent of swallowed errors, and clippy only reports them when told to.

## Fix

Add the [lints] table from the Rust stack profile (`fleetlint fix --apply` appends it); in a workspace member add `[lints] workspace = true`.

Agent instruction: Add [lints.rust] and [lints.clippy] tables per the Rust profile to Cargo.toml, or `[lints] workspace = true` in a workspace member.
