## Requirement

Release notes come from git-cliff, GoReleaser's changelog, release-please, changesets, or the release's own section cut from the generated CHANGELOG.md, so they match the CHANGELOG.

## Why

Hand-written release notes drift from the changelog and from what was shipped.

## Applies when

```cel
release.exists && tagged_workflows().size() > 0
```

## Fix

Use git-cliff --latest --strip header as the release body.

Agent instruction: Add a step that runs `git-cliff --latest --strip header -o release-notes.md` and pass it as the release body.

A finding of this rule points at the file `tagged_workflows().size() > 0 ? tagged_workflows()[0] : ".github/workflows/release.yml"` yields.
