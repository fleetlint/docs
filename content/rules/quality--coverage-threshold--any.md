# quality/coverage-threshold/any

A coverage floor is enforced

The stack-neutral implementation of [quality/coverage-threshold](quality--coverage-threshold.md): it checks stacks without an implementation of their own and repositories where no stack is detected, and its satisfiers count for every stack.

## Requirement

The `cover` recipe (of the scope's task runner or a parent Makefile) compares coverage with a minimum (a fail-under option, a `COVER_MIN` comparison), diff-cover runs with `--fail-under`, or a codecov.yml here or in a parent directory sets a status `target`. Comments and `echo` lines do not count.

## Why

A coverage number nobody enforces drifts down one "quick fix" at a time.

## Applies when

```cel
repo.stacks.size() > 0
```

## Fix

Make `make cover` fail below the floor (diff-cover --fail-under=80 is the stack-neutral option).

Agent instruction: Add a threshold to the cover recipe using the stack profile's tool (go: go-test-coverage or a cover script with a minimum; python: --cov-fail-under; node: coverageThreshold; rust: cargo llvm-cov --fail-under-lines; kotlin: kover verify).

A finding of this rule points at the file `taskrunner.file != "" ? taskrunner.file : "Makefile"` yields.
