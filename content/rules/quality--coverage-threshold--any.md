# quality/coverage-threshold/any

A coverage floor is enforced

The stack-neutral implementation of [quality/coverage-threshold](quality--coverage-threshold.md): it checks stacks without an implementation of their own, and its satisfiers count for every stack.

## Requirement

The `cover` recipe compares coverage with a minimum (a fail-under option, a `COVER_MIN` comparison), diff-cover runs with `--fail-under`, or codecov.yml sets a status `target`. Comments and `echo` lines do not count.

## Why

A coverage number nobody enforces drifts down one "quick fix" at a time.

## Parameters

- `skip`: `^\s*[@+-]*\s*(\{\{[^}]*\}\}\s*|\$[({][A-Za-z_]+[)}]\s*)?(#|//|echo\b|printf\b|(sudo\s+)?(go (install|get)|cargo b?install|pipx? install|pip3 install|python3? -m pip install|uv (tool |pip )?(install|add)|(npm|pnpm|yarn|bun) (i|install|add|global add)|gem install|bundle add|brew install|dotnet tool (install|update)|composer (global )?require|apt(-get)? install|curl|wget)\b[^;&]*$)`

## Fix

Make `make cover` fail below the floor (diff-cover --fail-under=80 is the stack-neutral option).

Agent instruction: Add a threshold to the cover recipe using the stack profile's tool (go: go-test-coverage or a cover script with a minimum; python: --cov-fail-under; node: coverageThreshold; rust: cargo llvm-cov --fail-under-lines; kotlin: kover verify).
