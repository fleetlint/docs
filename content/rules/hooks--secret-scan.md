# hooks/secret-scan

Hooks scan for secrets

## Requirement

A pre-commit hook (pre-commit/prek or lefthook's `pre-commit`) runs a secret scanner that blocks commits containing secrets: gitleaks, trufflehog, ggshield, detect-secrets or secretlint. `detect-private-key` alone finds only private key blocks and counts as a partial result (warning).

## Why

Secrets must be stopped before they enter history; removing them afterwards means rotation and rewrites.

## Fix

Add the gitleaks hook (repo: https://github.com/gitleaks/gitleaks) to .pre-commit-config.yaml, or `gitleaks git --pre-commit --staged` to lefthook's pre-commit.

Agent instruction: Add the gitleaks pre-commit hook to .pre-commit-config.yaml and run `prek update`; with lefthook add a pre-commit command running `gitleaks git --pre-commit --redact --staged --verbose`.

A finding of this rule points at the file `([".pre-commit-config.yaml", "lefthook.yml", "lefthook.yaml", "lefthook.toml", "lefthook.json", "lefthook.jsonc", ".lefthook.yml", ".lefthook.yaml", ".lefthook.toml", ".lefthook.json", ".lefthook.jsonc"].filter(f, file(f)) + [".pre-commit-config.yaml"])[0]` yields.
