## Requirement

`dart format` runs in a hook, the task runner or CI (with `--set-exit-if-changed` where it checks). Another formatter is added with `accept:`.

## Why

Without one formatter every editor reformats differently and diffs fill with whitespace churn that hides the real change.

## Fix

Add `dart format --set-exit-if-changed .` to the lint target and a dart format hook.

Agent instruction: Add `dart format --set-exit-if-changed .` to the lint target and the dart-format pre-commit hook; reformat in a separate commit.
