## Requirement

A SECURITY file at the root or in `.github/`, `docs/` or `.gitea/` explains how to report a vulnerability privately.

## Why

Reporters otherwise open public issues, which disclose the problem before a fix exists.

## Applies when

```cel
repo.public
```

## Check

```cel
exists("SECURITY*") || exists(".github/SECURITY*") || exists("docs/SECURITY*") || exists(".gitea/SECURITY*")
```

## Fix

Add SECURITY.md with a private contact and expected response time.
