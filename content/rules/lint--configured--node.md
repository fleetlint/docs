## Requirement

A linter is configured in the package or a parent directory: an ESLint flat config (`eslint.config.*`), Biome (`biome.json`) or oxlint (`.oxlintrc.json`). Another linter is added with `accept:`.

## Why

Without a type-aware linter, floating promises and any-typed code go unnoticed.

## Fix

Add an ESLint flat config; `fleetlint fix --apply` writes eslint.config.mjs and adds the eslint packages to devDependencies (then run the package manager's install).

Agent instruction: Add eslint.config.mjs with typescript-eslint strictTypeChecked and the plugins to devDependencies; install and fix what the linter reports.

`fleetlint fix` can apply this rule's fix automatically (2 action(s)).

A finding of this rule points at `eslint.config.mjs`.
