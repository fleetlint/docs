## Requirement

With Conan, conan.lock is tracked; with vcpkg, vcpkg.json sets a `builtin-baseline` (or vcpkg-configuration.json a registry `baseline`), which fixes every port version. A build without a package manager needs neither.

## Why

Builds are reproducible only when dependency versions are pinned in git.

## Check

```cel
((!file("conanfile.txt") && !file("conanfile.py")) || "conan.lock" in tracked()) && (!file("vcpkg.json") || text("vcpkg.json").contains("\"builtin-baseline\"")
    || (file("vcpkg-configuration.json") && text("vcpkg-configuration.json").contains("\"baseline\"")))
```

## Fix

Conan: `conan lock create .` and commit conan.lock; vcpkg: `vcpkg x-update-baseline --add-initial-baseline`.

Agent instruction: Run the package manager to produce the lockfile, remove any .gitignore entry for it, and commit it.

A finding of this rule points at the file `file("vcpkg.json") ? "vcpkg.json" : "conan.lock"` yields.
