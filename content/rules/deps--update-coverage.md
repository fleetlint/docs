# deps/update-coverage

Update automation covers every ecosystem

## Requirement

The update automation covers every detected stack plus GitHub Actions workflows and Dockerfiles: Renovate does unless `enabledManagers` leaves the ecosystem's manager out or the manager is switched off (`"<manager>": {"enabled": false}`); Dependabot needs an `updates` entry with the ecosystem's `package-ecosystem`. C/C++ and Hugo have no entry to check.

## Why

An automation that updates the npm packages but not the base image or the actions leaves exactly the parts nobody looks at to rot.

## Applies when

```cel
params.renovate.exists(f, file(f)) || file(".github/dependabot.yml") || file(".github/dependabot.yaml")
```

## Check

For each `item` in:

```cel
repo.stacks.filter(s, s in params.dependabot) + (exists(".github/workflows/*.y*ml") ? ["github-actions"] : []) + (exists("**/Dockerfile") || exists("**/Containerfile") || exists("**/*.Dockerfile") ? ["docker"] : [])
```

```cel
params.renovate.exists(f, file(f)
  && (!text(f).contains("enabledManagers") || params.managers[item].exists(m, text(f).matches(r'enabledManagers[^\]]*["\x27]' + m + r'["\x27]')))
  && !params.managers[item].exists(m, text(f).matches(r'["\x27]?' + m + r'["\x27]?\s*:\s*\{\s*["\x27]?enabled["\x27]?\s*:\s*false')))
|| ["dependabot.yml", "dependabot.yaml"].exists(n, file(".github/" + n)
  && yaml(".github/" + n) != null && "updates" in yaml(".github/" + n)
  && yaml(".github/" + n).updates.exists(u, "package-ecosystem" in u && string(u["package-ecosystem"]) in params.dependabot[item]))
```

## Parameters

- `dependabot`: `map[docker:[docker docker-compose] dotnet:[nuget] flutter:[pub] github-actions:[github-actions] go:[gomod] java:[maven gradle] kotlin:[gradle] node:[npm bun] php:[composer] python:[pip uv] ruby:[bundler] rust:[cargo]]`
- `managers`: `map[docker:[dockerfile docker-compose] dotnet:[nuget] flutter:[pub] github-actions:[github-actions] go:[gomod] java:[maven gradle maven-wrapper gradle-wrapper] kotlin:[gradle] node:[npm bun] php:[composer] python:[pep621 poetry pip_requirements pip-compile pipenv setup-cfg pep723] ruby:[bundler] rust:[cargo]]`
- `renovate`: `[renovate.json renovate.json5 .renovaterc .renovaterc.json .renovaterc.json5 .github/renovate.json .github/renovate.json5 .gitea/renovate.json .gitea/renovate.json5 .forgejo/renovate.json .forgejo/renovate.json5 .gitlab/renovate.json .gitlab/renovate.json5]`

## Fix

Add an `updates` entry per ecosystem to .github/dependabot.yml, or switch to Renovate (config:recommended covers every manager).

Agent instruction: Add the missing ecosystems to the Dependabot updates list (or the Renovate enabledManagers list) with the same schedule as the existing entries.
