# deps/license-check/node

Dependency licenses are checked against an allowlist

## Requirement

A task-runner recipe, a package.json script or a CI step runs license-checker with `--onlyAllow`/`--failOn`, licensee or license-compliance, or a stack-neutral license checker.

## Why

A dependency under an incompatible license is found cheaply before it is merged and expensively after a release.

## Fix

Run `npx license-checker-rseidelsohn --onlyAllow "MIT;ISC;Apache-2.0;BSD-3-Clause"` in the `audit` target.

Agent instruction: Add the stack's license checker to the audit target with an allowlist compatible with the repository's own license; report dependencies outside it instead of widening the list.

A finding of this rule points at the file `taskrunner.file != "" ? taskrunner.file : "Makefile"` yields.
