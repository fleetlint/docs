## Requirement

A formatter is wired into the Gradle build (this build, a parent build or a convention plugin): Spotless, ktlint or ktfmt, or one runs in a hook, the task runner or CI. Another formatter is added with `accept:`.

## Why

Without one formatter every editor reformats differently and diffs fill with whitespace churn that hides the real change.

## Fix

Add Spotless with ktlint (or ktfmt) to the Gradle build and run spotlessCheck in the hooks.

Agent instruction: Add the Spotless Gradle plugin with ktlint() for Kotlin sources, spotlessCheck to the lint target and a hook; reformat in a separate commit.

See: <https://fleetlint.org/baseline/#static-analysis>, <https://fleetlint.org/stacks/#kotlin-jvm--android>
