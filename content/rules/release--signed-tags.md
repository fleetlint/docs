# release/signed-tags

Release tags are signed

| | |
|---|---|
| Severity | warning |
| Tiers | 1 |
| Stacks | any |
| Scope | root |
| Kind | expr |
| Source | fleetlint-recommended@0.1.0 |

## Requirement

The newest `params.recent` version tags are annotated tags with a PGP, SSH or X.509 signature (`git tag -s`). Tags created through a forge's release page are lightweight and fail; create the tag locally and push it, then publish the release from it.

## Why

A signed tag ties the released commit to a maintainer's key; the release pipeline then builds from something that can be verified, not just from a name.

## Applies when

```cel
repo.has_git && tags().exists(t, t.matches("^v?[0-9]+\\.[0-9]+\\.[0-9]+"))
```

## Check

For each `item` in:

```cel
tags().filter(t, t.matches("^v?[0-9]+\\.[0-9]+\\.[0-9]+")).slice(0,
  tags().filter(t, t.matches("^v?[0-9]+\\.[0-9]+\\.[0-9]+")).size() < int(params.recent)
    ? tags().filter(t, t.matches("^v?[0-9]+\\.[0-9]+\\.[0-9]+")).size() : int(params.recent))
```

```cel
tag_signed(item)
```

## Parameters

- `recent`: `3`

## Fix

Set `git config tag.gpgsign true` (and `gpg.format ssh` with your SSH key) so every tag is signed; recreate unsigned release tags only if nothing depends on them.

Agent instruction: Tell the user which tags are unsigned and how to configure tag.gpgsign; do not delete or move tags.

See: <https://fleetlint.org/baseline/#releases>
