# repo/toolchain-pinned/rust

Toolchain version is pinned

## Requirement

`rust-toolchain.toml` (or `rust-toolchain`) exists, or `.tool-versions`/mise names rust with a version. `rust-version` in Cargo.toml is the minimum supported version, not a pin.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
file("rust-toolchain.toml") || file("rust-toolchain") || scan(".tool-versions", r'^\s*(rust)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(rust)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Add rust-toolchain.toml with `[toolchain] channel = "1.x.y"`.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.
