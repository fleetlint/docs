## Requirement

The JDK is pinned: `.java-version`, `.sdkmanrc` with `java=`, a Gradle toolchain (`JavaLanguageVersion.of(n)`, `jvmToolchain(n)`) or `gradle-daemon-jvm.properties`, the Maven enforcer's `requireJavaVersion`, or `.tool-versions`/mise naming java. The Gradle and Maven wrappers pin the build tool, not the JDK, and `maven.compiler.release` only sets the bytecode level; none of them counts.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
scan(".java-version", r'^\s*\d').size() > 0 || scan(".sdkmanrc", r'^\s*java\s*=\s*\d').size() > 0 || (file("gradle/gradle-daemon-jvm.properties") && text("gradle/gradle-daemon-jvm.properties").matches(r'toolchainVersion\s*=\s*\d')) || glob("**/build.gradle*").exists(f, text(f).matches(r'languageVersion(\.set\(|\s*=\s*)\s*JavaLanguageVersion\.of\(\s*\d|jvmToolchain\s*\(\s*\d')) || (file("pom.xml") && text("pom.xml").matches(r'<requireJavaVersion>\s*<version>\s*[\[(]?\d')) || scan(".tool-versions", r'^\s*(java)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(java)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Add a Gradle toolchain (`java { toolchain { languageVersion = JavaLanguageVersion.of(21) } }`) or a .java-version file.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.
