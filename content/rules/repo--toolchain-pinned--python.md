## Requirement

`.python-version` names a version, or `.tool-versions`/mise names python with a version. `requires-python` is a range, not a pin.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
scan(".python-version", r'^\s*\d').size() > 0 || scan(".tool-versions", r'^\s*(python)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(python)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Run `uv python pin 3.x` (writes .python-version).

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.
