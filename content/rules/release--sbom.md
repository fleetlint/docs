# release/sbom

Releases publish an SBOM

A capability keyed by published artifact: each kind the release publishes is checked by its own implementation, and every one must pass. Implemented for [android-app](release--sbom--android-app.md), [apple-app](release--sbom--apple-app.md), [crate](release--sbom--crate.md), [gem](release--sbom--gem.md), [helm-chart](release--sbom--helm-chart.md), [image](release--sbom--image.md), [maven](release--sbom--maven.md), [npm](release--sbom--npm.md), [nuget](release--sbom--nuget.md), [pub](release--sbom--pub.md), [pypi](release--sbom--pypi.md), [release-files](release--sbom--release-files.md).

## Requirement

Every artifact a release publishes that carries its own dependencies (files on a forge release, a container image, a Maven artifact, a NuGet package, an Android app) comes with an SPDX or CycloneDX SBOM generated inside the release pipeline and published next to it. A package the registry resolves from a manifest (npm, PyPI, crates.io, RubyGems, pub.dev) is not checked: the registry holds its dependency graph. Each artifact kind's implementation names its producers; repositories add producers with `accept:`.

## Why

Consumers and scanners need to know what is inside an artifact; generating the SBOM in the pipeline ties it to the exact build.

## Applies when

```cel
release.exists || repo.artifacts.size() > 0
```

## Fix

Run the artifact's SBOM producer in the release workflow (`fleetlint explain release/sbom/<artifact>`): syft or GoReleaser `sboms:` for release files, BuildKit `sbom: true` or `cosign attest --type spdx` for an image, the CycloneDX build plugin for Maven, NuGet and Android; upload the files with the release.

Agent instruction: In the tag-triggered release workflow add a step producing an SPDX JSON SBOM for each published artifact (syft for files, BuildKit `sbom: true` for images, the stack's CycloneDX plugin otherwise) and include the files in the release upload step. Do not change other steps. If the repo uses GoReleaser, add a `sboms:` section instead.
