Package manifest declares the license

## Requirement

pyproject.toml sets `project.license` (SPDX, PEP 639), `license-files` or a license classifier, unless it carries the `Private :: Do Not Upload` classifier.

## Why

Registries, SBOM tools and license checkers read the manifest, not the LICENSE file.

## Capability applies when

```cel
repo.public
```

## Check

```cel
!file("pyproject.toml") || scan("pyproject.toml", r'Private :: Do Not Upload').size() > 0 || scan("pyproject.toml", r'^\s*license(-files)?\s*=|License ::').size() > 0
```

## Fix

Set `license = "<SPDX id>"` in pyproject.toml's `[project]` table.

Agent instruction: Set the manifest's license field to the SPDX identifier matching the LICENSE file; ask if the LICENSE text is not a recognised license.
