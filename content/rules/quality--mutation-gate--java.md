## Requirement

Pitest runs on the core modules (pitest-maven or the Gradle Pitest plugin), from the task runner or a workflow.

## Why

Coverage says a line ran; a surviving mutant says the tests would not notice if it were wrong.

## Fix

Add pitest-maven or the info.solidsoft.pitest Gradle plugin with `mutationThreshold` for the core packages and run it weekly.

Agent instruction (from [quality/mutation-gate](quality--mutation-gate.md#fix)): Add a mutate target that runs the stack's mutation tool on the core packages with a survivor threshold, and a weekly workflow that calls it.

A finding that names no file points at the first existing file of `pom.xml`, `build.gradle.kts` or `build.gradle`, else `pom.xml`.
