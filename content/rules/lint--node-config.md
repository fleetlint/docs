# lint/node-config

## Requirement

tsconfig.json has strict: true (plus noUncheckedIndexedAccess) and ESLint strictTypeChecked or Biome is configured.

## Why

Without strict types and a type-aware linter, floating promises and any-typed code go unnoticed.

## Check

```cel
(file("tsconfig.json") && json("tsconfig.json") != null && has(json("tsconfig.json").compilerOptions)
  && has(json("tsconfig.json").compilerOptions.strict) && json("tsconfig.json").compilerOptions.strict == true)
&& (exists("eslint.config.*") || file("biome.json") || file("biome.jsonc"))
```

## Fix

Enable strict in tsconfig.json and add an eslint flat config; `fleetlint fix --apply` writes eslint.config.mjs, merges the strict flags into tsconfig.json and adds the eslint packages to devDependencies (then run the package manager's install).

Agent instruction: Set compilerOptions.strict and noUncheckedIndexedAccess in tsconfig.json; add eslint.config.mjs with typescript-eslint strictTypeChecked and the plugins to devDependencies; install and fix what the linter reports.
