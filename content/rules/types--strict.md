## Requirement

Where the stack has an optional or configurable type checker, it runs in its strictest mode, configured in the repository.

## Why

A lenient type checker lets untyped and implicitly dynamic values through, which is where the bugs it exists to catch hide.

## Fix

Switch the type checker to strict mode (see https://fleetlint.org/stacks/).

Agent instruction: Switch the type checker to strict mode and list the errors that appear instead of adding ignores.

See: <https://fleetlint.org/baseline/#static-analysis>
