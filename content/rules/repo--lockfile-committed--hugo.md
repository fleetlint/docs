# repo/lockfile-committed/hugo

[repo/lockfile-committed](repo--lockfile-committed.md) does not apply to hugo: nothing is checked for it.

## Why it does not apply

Hugo has no lockfile of its own. The go.sum of Hugo modules is not checked: a site's go.mod does not make it a Go project unless Go sources sit next to it. npm tooling's lockfile is checked as Node, and themes added as git submodules are pinned by commit.
