# release/trusted-publishing/release-files

[release/trusted-publishing](release--trusted-publishing.md) does not apply to the `release-files` artifact: nothing is checked for it.

## Why it does not apply

Release files are uploaded with the forge's own job token (GITHUB_TOKEN, the Gitea or GitLab job token), which is minted per run already.
