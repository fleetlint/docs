## Requirement

No analyzer in the build is set to let findings pass (`failOnViolation`, `failsOnError` or `failOnError` false, `ignoreFailures = true`), and Checkstyle, when used, fails on warnings too: its configuration sets severity error, `violationSeverity` is warning, or Gradle's `maxWarnings` is 0.

## Why

An analyzer whose findings only print is skipped by everyone; Checkstyle's defaults report most checks as warnings that do not fail the build.

## Fix

Remove the settings that ignore failures and set Checkstyle's severity to error; `fleetlint fix --apply` writes config/checkstyle/checkstyle.xml with severity error when it is missing (Gradle's default location; Maven needs configLocation pointing at it).

Agent instruction: Remove failOnViolation/failOnError false and ignoreFailures true from the build, make Checkstyle fail on warnings (severity error in its configuration), and fix what then fails.
