## Requirement

The detekt configuration sets `active: true` for every rule in `params.required` (ruleset.Rule): swallowed and too-generic exceptions, empty catch blocks, method length and cognitive complexity. `detekt --generate-config` writes a full configuration to edit.

## Why

The compiler accepts a swallowed exception and a 400-line method; detekt is the only place these are refused, and only when the rules are on.

## Applies when

```cel
exists("**/detekt*.yml") || exists("**/detekt*.yaml")
```

## Check

For each `item` in:

```cel
params.required
```

```cel
glob("**/detekt*.y*ml").exists(f, yaml(f) != null
  && item.split(".")[0] in yaml(f)
  && item.split(".")[1] in yaml(f)[item.split(".")[0]]
  && has(yaml(f)[item.split(".")[0]][item.split(".")[1]].active)
  && yaml(f)[item.split(".")[0]][item.split(".")[1]].active == true)
```

## Parameters

- `required`: `[exceptions.SwallowedException exceptions.TooGenericExceptionCaught empty-blocks.EmptyCatchBlock complexity.LongMethod complexity.CognitiveComplexMethod]`

## Fix

Set the reported rules to `active: true` in the detekt configuration (thresholds: LongMethod 50, CognitiveComplexMethod 15).

Agent instruction: Set each reported rule to active: true in the detekt configuration and fix the findings it produces instead of adding a baseline entry.
