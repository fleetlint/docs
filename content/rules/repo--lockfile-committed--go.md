## Requirement

go.sum is tracked when go.mod requires any module.

## Why

Builds are reproducible only when dependency versions are pinned in git.

## Check

```cel
"go.sum" in tracked() || scan("go.mod", r'^\s*require\b').size() == 0
```

## Fix

Run `go mod tidy` and commit go.sum.
