## Requirement

PHPStan (`phpstan.neon.dist`, level max with strict rules) or Psalm, plus PHP CS Fixer, Pint or PHP_CodeSniffer, all configured in the repository and run by the lint target.

## Why

PHP's type system is enforced at runtime only; the analyzer is the compile step the language lacks.

## Check

```cel
(exists("phpstan.neon*") || exists("phpstan.dist.neon") || file("psalm.xml") || file("psalm.xml.dist")) && (exists(".php-cs-fixer*.php") || file("pint.json") || exists("phpcs.xml*") || exists(".php_cs*"))
```

## Fix

Add phpstan.neon.dist, .php-cs-fixer.dist.php and the packages in require-dev (`fleetlint fix --apply` does all three).
