# lint/strict/dotnet

Nullable, recommended analyzers and warnings as errors are on

Implements [lint/strict](lint--strict.md) for dotnet.

## Requirement

Directory.Build.props (or every project file) sets `<Nullable>enable`, `<TreatWarningsAsErrors>true` and `<AnalysisLevel>latest-recommended` or `latest-all` (a version number or `<AnalysisMode>Recommended`/`All` also counts; for the analysis level, `dotnet_analyzer_diagnostic.severity = warning` or `error` in .editorconfig counts too).

## Why

Analyzers at their default level report little, and warnings that do not fail the build are ignored; `latest-minimum` or `latest-none` keep the switch but not the checks.

## Applies when

```cel
["", "../", "../../", "../../../"].exists(d, file(d + "Directory.Build.props")
  || (file(d + ".editorconfig") && text(d + ".editorconfig").contains("dotnet_analyzer_diagnostic")))
|| (glob("**/*.csproj") + glob("**/*.fsproj")).exists(p, text(p).matches("<(Nullable|TreatWarningsAsErrors|AnalysisLevel|AnalysisMode)>"))
```

## Check

For each `item` in:

```cel
params.required
```

```cel
[item == "Nullable" ? "<Nullable>\\s*enable\\s*<"
  : (item == "TreatWarningsAsErrors" ? "<TreatWarningsAsErrors>\\s*true\\s*<"
  : (item == "AnalysisLevel" ? "<AnalysisLevel>\\s*(latest|preview|\\d+(\\.\\d+)?)-(recommended|all)\\s*<|<AnalysisMode>\\s*(Recommended|All)\\s*<"
  : "<" + item + ">\\s*true\\s*<"))]
.exists(re,
  ["", "../", "../../", "../../../"].exists(d, file(d + "Directory.Build.props") && text(d + "Directory.Build.props").matches(re))
  || [glob("**/*.csproj") + glob("**/*.fsproj")].exists(ps, ps.size() > 0 && ps.all(p, text(p).matches(re)))
  || (item == "AnalysisLevel" && ["", "../", "../../", "../../../"].exists(d, file(d + ".editorconfig")
    && text(d + ".editorconfig").matches("(?m)^\\s*dotnet_analyzer_diagnostic\\.severity\\s*=\\s*(warning|error)\\b"))))
```

## Parameters

- `required`: `[Nullable TreatWarningsAsErrors AnalysisLevel]`
