# release/semver-tags

Tags are semantic versions

| | |
|---|---|
| Severity | warning |
| Tiers | all |
| Stacks | any |
| Scope | root |
| Kind | expr |
| Source | library v0.1.0 |
| Selected by | fleetlint-recommended@v0.1.0 |

## Requirement

Every tag is `vMAJOR.MINOR.PATCH[-prerelease][+build]` (the `v` optional). Monorepos prefix a component: `path/to/module/v1.2.3`, `pkg@1.2.3` or `@scope/pkg@1.2.3` (changesets) and `pkg-v1.2.3` (release-please).

## Why

Release tooling, changelog generation and dependency resolvers all key on the pattern.

## Applies when

```cel
repo.has_git && tags().size() > 0
```

## Check

For each `item` in:

```cel
tags()
```

```cel
item.matches("^(([A-Za-z0-9_.-]+/)*v?|(@[A-Za-z0-9_.-]+/)?[A-Za-z0-9_.-]+@v?|[A-Za-z0-9_.]+(-[A-Za-z0-9_.]+)*-v?)[0-9]+\\.[0-9]+\\.[0-9]+(-[0-9A-Za-z.-]+)?(\\+[0-9A-Za-z.-]+)?$")
```

## Fix

Delete or rename the offending tags; tag releases as vX.Y.Z from now on.

Agent instruction: List the offending tags for the user; do not delete tags without confirmation.

See: <https://fleetlint.org/baseline/#releases>
