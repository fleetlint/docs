# deps/update-automation

Dependency updates are automated

## Requirement

Renovate (preferred, works on GitHub and Gitea) or Dependabot keeps dependencies and pinned actions current. Tool versions count too: Renovate reads version-manager files (`mise.toml`, `.tool-versions`) directly, hook revisions once its pre-commit manager is enabled, and a version in a task runner file or a workflow when a `# renovate: datasource=… depName=…` comment sits above a `*_VERSION` variable.

## Why

Unpinned is unsafe and pinned-but-stale is unsafe too; only automation keeps both true.

## Check

```cel
exists("renovate.json*") || exists(".renovaterc*") || exists(".github/renovate.json*") || file(".github/dependabot.yml") || file(".gitea/dependabot.yml") || file(".gitlab/renovate.json")
```

## Fix

Add renovate.json; `fleetlint fix --apply` writes one that also covers pinned actions, hook revisions and annotated tool versions. Then install the Renovate app on the repository.

Agent instruction: Add renovate.json extending config:recommended, helpers:pinGitHubActionDigests, customManagers:makefileVersions and customManagers:githubActionsVersions, with the pre-commit manager enabled. Put a `# renovate: datasource=… depName=…` comment above every pinned tool version in the task runner file and the workflows.

`fleetlint fix` can apply this rule's fix automatically (1 action(s)).

See: <https://fleetlint.org/baseline/#dependencies>
