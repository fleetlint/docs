# public/manifest-license/php

Package manifest declares the license

## Requirement

A library's composer.json has `license` (an SPDX identifier or a list of them); `"type": "project"` (an application) is not checked.

## Why

Registries, SBOM tools and license checkers read the manifest, not the LICENSE file.

## Capability applies when

```cel
repo.public
```

## Check

```cel
!file("composer.json") || json("composer.json") == null || (has(json("composer.json").type) && json("composer.json").type == "project") || has(json("composer.json").license)
```

## Fix

Add `"license": "<SPDX id>"` to composer.json.

Agent instruction: Set the manifest's license field to the SPDX identifier matching the LICENSE file; ask if the LICENSE text is not a recognised license.
