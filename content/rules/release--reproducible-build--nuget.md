# release/reproducible-build/nuget

Release builds are reproducible

Implements [release/reproducible-build](release--reproducible-build.md) for the `nuget` artifact: it runs when the release publishes one (see [artifacts](capabilities.md#artifacts)).

## Requirement

`ContinuousIntegrationBuild` is true for the packaging build (in a project or Directory.Build.props, or `-p:ContinuousIntegrationBuild=true` in the workflow that pushes the package), which maps source paths away; deterministic compilation is the SDK default. Or `SOURCE_DATE_EPOCH` is set for the release build.

## Why

When anyone can rebuild a release bit for bit from the tag, a tampered artifact or a compromised build machine shows up as a mismatch.

release.exists || repo.artifacts.size() > 0

## Fix

Add `<ContinuousIntegrationBuild Condition="'$(CI)' == 'true'">true</ContinuousIntegrationBuild>` to Directory.Build.props.

Agent instruction: Add the stack's reproducibility settings to the release build and derive SOURCE_DATE_EPOCH from `git log -1 --format=%ct`; do not change what is built.

A finding of this rule points at `Directory.Build.props`.
