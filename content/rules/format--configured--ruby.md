## Requirement

RuboCop or Standard is configured in the project or a parent directory (their layout cops format the code), or rubocop, standardrb, rufo or syntax_tree runs in a hook, the task runner or CI. Another formatter is added with `accept:`.

## Why

Without one formatter every editor reformats differently and diffs fill with whitespace churn that hides the real change.

## Fix

Add .rubocop.yml and run `rubocop --autocorrect` in a hook.

Agent instruction: Add .rubocop.yml and a rubocop hook with --autocorrect; reformat in a separate commit.
