# repo/toolchain-pinned/dotnet

Toolchain version is pinned

Implements [repo/toolchain-pinned](repo--toolchain-pinned.md) for dotnet.

## Requirement

global.json sets `sdk.version`, or `.tool-versions`/mise names dotnet with a version.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
file("global.json") && text("global.json").matches(r'"version"\s*:\s*"\d') || scan(".tool-versions", r'^\s*(dotnet|dotnet-core)\s+\S*\d').size() > 0 || ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(f,
     scan(f, r'^\s*"?(dotnet|dotnet-core)"?\s*=\s*[^#\n]*\d').size() > 0)
```

## Fix

Run `dotnet new globaljson --sdk-version <version> --roll-forward latestFeature`.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

See: <https://fleetlint.org/baseline/#hygiene>, <https://fleetlint.org/stacks/>, <https://fleetlint.org/stacks/#net>
