## Requirement

`analyzer.language` in the nearest analysis_options.yaml sets every mode in `params.required` to true, directly, through a local file it includes, or by including very_good_analysis.

## Why

Each mode closes a different hole through which `dynamic` enters the program unnoticed.

## Applies when

```cel
["", "../", "../../", "../../../"].exists(d, file(d + "analysis_options.yaml"))
```

## Check

For each `item` in:

```cel
params.required
```

```cel
[["", "../", "../../", "../../../"].filter(d, file(d + "analysis_options.yaml"))] .exists(l, [l[0]].exists(d, [yaml(d + "analysis_options.yaml")].exists(a, a != null && (
  (has(a.analyzer) && a.analyzer != null && "language" in a.analyzer && a.analyzer.language != null
    && item in a.analyzer.language)
    ? a.analyzer.language[item] == true
    : has(a.include) && (type(a.include) == list ? a.include : dyn([a.include])).exists(i,
        i.startsWith("package:very_good_analysis/")
        || (!i.startsWith("package:") && file(d + i) && [yaml(d + i)].exists(b, b != null && has(b.analyzer) && b.analyzer != null
          && "language" in b.analyzer && b.analyzer.language != null && item in b.analyzer.language
          && b.analyzer.language[item] == true)))))))
```
