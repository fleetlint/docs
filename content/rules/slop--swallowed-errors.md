# slop/swallowed-errors

Errors are not swallowed

## Requirement

No empty catch blocks (JavaScript, Java, Kotlin, C#, PHP, Dart), no `except: pass`, no `_ = err`, no Ruby `rescue nil` or `rescue; end`. Only single-line forms are detected; the stack's linter covers the rest.

## Why

A swallowed error turns a failure with a cause into a wrong result without one.

## Check

For each `item` in:

```cel
codegrep("nontest", r'catch\s*(\([^)]*\))?\s*\{\s*\}|except[^:]*:\s*pass\b|\b_\s*=\s*err\b|\.catch\(\s*\(\)\s*=>\s*(\{\s*\}|null|undefined)\s*\)|catch \(_\)|\brescue\s+nil\b|\brescue(\s+[\w:]+)?(\s*=>\s*\w+)?\s*;\s*end\b')
```

```cel
false
```

## Fix

Handle the error, wrap and return it, or log it where it is handled.

Agent instruction: Propagate the error with context unless the surrounding code shows it is safe to ignore; then say why in a comment.
