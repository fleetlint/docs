## Requirement

ruff format or black runs in a hook, the task runner or CI, or is configured (`[tool.ruff.format]` or `[tool.black]` in pyproject.toml). Another formatter is added with `accept:`.

## Why

Without one formatter every editor reformats differently and diffs fill with whitespace churn that hides the real change.

## Fix

Add `ruff format` to the fmt target and a ruff-format hook.

Agent instruction: Add `uv run ruff format` to the fmt target and the ruff-format pre-commit hook; reformat the code base in a separate commit.
