## Requirement

A pyproject `[project]` without scripts runs `griffe check` against the previous tag.

## Why

A breaking change in a minor release is found by every user at once; the check finds it before the tag.

## Applies when

```cel
toml("pyproject.toml") != null && has(toml("pyproject.toml").project) && !has(toml("pyproject.toml").project.scripts)
```

## Fix

Run `griffe check <package> --against $(git describe --tags --abbrev=0)` in the release workflow.

Agent instruction: Add the stack's API compatibility tool to the release workflow, comparing against the latest tag; on a breaking change bump the major version instead of silencing the tool.
