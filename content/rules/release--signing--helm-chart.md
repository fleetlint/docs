# release/signing/helm-chart

Release artifacts are signed

Implements [release/signing](release--signing.md) for the `helm-chart` artifact: it runs when the release publishes one (see [artifacts](capabilities.md#artifacts)).

## Requirement

A chart pushed to an OCI registry is signed by digest with `cosign sign`; a chart in a chart repository carries a provenance file (`helm package --sign`, chart-releaser `--sign`).

## Why

Checksums prove integrity; only a signature proves who built it.

## Capability applies when

```cel
release.exists || repo.artifacts.size() > 0
```

## Fix

OCI: `cosign sign --yes <registry>/<chart>@<digest>` after `helm push`. Chart repository: `helm package --sign --key <name> --keyring <file>` so a `.prov` file is published next to the chart.

Agent instruction: Use the artifact's own signing format when it has one. Otherwise add sigstore/cosign-installer and a signing step after the artifacts are built. Files: `cosign sign-blob --yes --bundle checksums.txt.sigstore.json checksums.txt` and upload the bundle. Container image: `cosign sign --yes <image>@<digest>` using the digest output of the build step, with `id-token: write` on the job.

See: <https://fleetlint.org/baseline/#releases>, <https://helm.sh/docs/topics/provenance/>
