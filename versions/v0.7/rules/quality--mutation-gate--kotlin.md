## Requirement

Pitest runs on the core modules (the Gradle Pitest plugin or pitest-maven), from the task runner or a workflow. Pitest mutates JVM bytecode; Kotlin Multiplatform code is covered only through its JVM or Android host tests.

## Why

Coverage says a line ran; a surviving mutant says the tests would not notice if it were wrong.

## Fix

Add the info.solidsoft.pitest Gradle plugin with `mutationThreshold` for the core modules and run `./gradlew pitest` weekly.

Agent instruction: Add a mutate target that runs the stack's mutation tool on the core packages with a survivor threshold, and a weekly workflow that calls it.
