## Requirement

gremlins (or go-mutesting) runs on the core packages, from the task runner or a workflow.

## Why

Coverage says a line ran; a surviving mutant says the tests would not notice if it were wrong.

## Fix

Add a `mutate` target running `gremlins unleash` on the core packages with a survivor threshold (`--threshold-efficacy`), and run it weekly.
