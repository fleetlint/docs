## Requirement

Every stack has a linter beyond the compiler, configured in the repository. A configuration in a parent directory counts for the projects below it when the tool reads it from there.

## Why

Without a committed configuration every developer's editor runs different checks and the build runs none.

## Fix

Configure the stack's linter as described in the stack profile (https://fleetlint.org/stacks/).

Agent instruction: Configure the stack's linter from the stack profile and run it from the lint target; fix what it reports instead of disabling checks.
