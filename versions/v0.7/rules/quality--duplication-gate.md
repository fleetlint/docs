# quality/duplication-gate

Duplicated code is measured

A capability: each stack checks it with its own tools. Implemented for [any](quality--duplication-gate--any.md), [go](quality--duplication-gate--go.md), [java](quality--duplication-gate--java.md), [kotlin](quality--duplication-gate--kotlin.md), [python](quality--duplication-gate--python.md).

Combine: `all`. Every implementation that runs must pass: each stack in the repository meets the requirement with its own tools.

## Requirement

A duplication detector runs in the task runner, the hooks or CI and is not switched off: the stack's own (golangci-lint `dupl`, pylint `duplicate-code`, PMD CPD) or a stack-neutral one (jscpd, Simian, duplo, Sonar). Another tool is added with `accept:`.

## Why

Near-duplicate implementations are how a fix lands in one copy and not the other; a detector makes the second copy visible at review time.

## Fix

Enable `dupl` in .golangci.yml, or add `jscpd` to the lint target (see https://fleetlint.org/stacks/ for the stack's tool).

Agent instruction: Add the stack's duplication detector to the lint target with a threshold, and remove or merge the duplicates it reports rather than raising the threshold.
