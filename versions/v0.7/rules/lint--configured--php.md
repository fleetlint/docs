## Requirement

PHPStan (`phpstan.neon.dist`) or Psalm (`psalm.xml`) is configured in the project or a parent directory. Another analyzer is added with `accept:`.

## Why

PHP's type system is enforced at runtime only; the analyzer is the compile step the language lacks.

## Fix

Add phpstan.neon.dist and the packages in require-dev (`fleetlint fix --apply` does both).

Agent instruction: Add phpstan.neon.dist from the template, require phpstan/phpstan and phpstan/phpstan-strict-rules in require-dev, and fix what it reports or generate a baseline.

`fleetlint fix` can apply this rule's fix automatically (2 action(s)).
