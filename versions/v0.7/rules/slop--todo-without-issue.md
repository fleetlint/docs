# slop/todo-without-issue

TODOs reference an issue

## Requirement

Every TODO, FIXME, XXX or HACK comment names an issue: `TODO(#123)`, `TODO(ABC-123)` or an issue URL on the same line.

## Why

An untracked TODO is a wish; a tracked one has an owner and can be closed.

## Check

For each `item` in:

```cel
codegrep("code", r'(^\s*\*|(^|\s)(//+|#+|/\*+))\s*(.*[^-\w])?(TODO|FIXME|XXX|HACK)([^-\w]|$)')
```

```cel
item.text.matches(r'\b(TODO|FIXME|XXX|HACK)\b\s*\((#|[A-Z][A-Z0-9]+-)\d+\)|https?://\S+/(issues?|browse|-/issues|merge_requests|pull)/\S*\d')
```

## Fix

Open an issue and reference it, or do the work, or delete the note.

Agent instruction: Report each note; do not invent issue numbers.
