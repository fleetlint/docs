A library checks its API against the previous release

## Requirement

A packable project enables package validation against the previous version (`EnablePackageValidation` with `PackageValidationBaselineVersion`) or runs ApiCompat.

## Why

A breaking change in a minor release is found by every user at once; the check finds it before the tag.

## Applies when

```cel
glob("**/*.csproj").exists(f, text(f).matches(r'<(PackageId|IsPackable>true)'))
```

## Fix

Set `<EnablePackageValidation>true</EnablePackageValidation>` and `<PackageValidationBaselineVersion>` (the previous release) in the packable project.

Agent instruction: Add the stack's API compatibility tool to the release workflow, comparing against the latest tag; on a breaking change bump the major version instead of silencing the tool.

A finding of this rule points at `Directory.Build.props`.
