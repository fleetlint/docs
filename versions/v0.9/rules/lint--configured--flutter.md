## Requirement

analysis_options.yaml (in the package or a parent directory) includes a lint set such as flutter_lints, lints or very_good_analysis, or enables linter rules itself.

## Why

The Dart analyzer only reports what a lint set switches on; without one, `flutter analyze` checks little beyond compile errors.

## Fix

Add analysis_options.yaml including package:flutter_lints (`fleetlint fix --apply` writes one with the strict modes on).

Agent instruction: Add analysis_options.yaml from the template (flutter_lints plus the strict modes and slop guards); run `flutter analyze --fatal-infos` and fix what it reports.

`fleetlint fix` can apply this rule's fix automatically (1 action(s)).
