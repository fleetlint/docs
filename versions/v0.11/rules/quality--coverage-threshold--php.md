## Requirement

PHPUnit has no coverage minimum of its own: phpunit-coverage-check (`coverage-check clover.xml 80`) runs after the tests, or a stack-neutral floor applies (diff-cover `--fail-under` on the Cobertura report).

## Why

A coverage number nobody enforces drifts down one "quick fix" at a time.

## Fix

Run `vendor/bin/coverage-check build/clover.xml 80` after PHPUnit in the `cover` target.

Agent instruction (from [quality/coverage-threshold](quality--coverage-threshold.md#fix)): Add a threshold to the cover recipe with the coverage tool of the stack profile (https://fleetlint.org/stacks/), or run diff-cover --fail-under on the coverage report.

A finding that names no file points at the task runner's file, or `Makefile` when there is none.
