## Requirement

JaCoCo's `check` goal with a `<minimum>` in pom.xml, JaCoCo `violationRules` (jacocoTestCoverageVerification) or Kover `minBound` verification in a Gradle build, or a stack-neutral floor applies.

## Why

A coverage number nobody enforces drifts down one "quick fix" at a time.

## Fix

Add a Kover (or JaCoCo) verification rule with a minimum and run its verify task in `cover`.

Agent instruction (from [quality/coverage-threshold](quality--coverage-threshold.md#fix)): Add a threshold to the cover recipe with the coverage tool of the stack profile (https://fleetlint.org/stacks/), or run diff-cover --fail-under on the coverage report.
