# release/reproducible-build/npm

[release/reproducible-build](release--reproducible-build.md) does not apply to the `npm` artifact: nothing is checked for it.

## Why it does not apply

npm, pnpm, yarn and bun pack a package with fixed file timestamps, so the tarball of a commit is the same wherever it is built; nothing to configure.
