## Requirement

CHANGELOG.md exists and has at least one `## ` section heading; which versions it lists and their format are not checked.

## Why

Users and future you need to know what changed between versions without reading commits.

## Check

```cel
file("CHANGELOG.md") && scan("CHANGELOG.md", "^##\\s+\\S").size() > 0
```

## Fix

Add CHANGELOG.md with an `## [Unreleased]` section (`fleetlint fix --apply` writes it), then keep one `## ` section per version, as Keep a Changelog, git-cliff, release-please and changesets write it.

Agent instruction: Create CHANGELOG.md from the template; if cliff.toml exists, regenerate it with `git-cliff -o CHANGELOG.md` and review the result.

`fleetlint fix` can apply this rule's fix automatically (1 action(s)).
