# repo/codeowners

CODEOWNERS names reviewers

## Requirement

A CODEOWNERS file exists at the root or in `.github/`, `.gitlab/`, `docs/` or `.gitea/`; the paths and owners in it are not checked.

## Why

Review ownership that lives in people's heads does not survive a holiday.

## Check

```cel
file("CODEOWNERS") || file(".github/CODEOWNERS") || file("docs/CODEOWNERS") || file(".gitea/CODEOWNERS") || file(".gitlab/CODEOWNERS")
```

## Fix

Add .github/CODEOWNERS with a default owner line, so review requests for every path reach someone.

Agent instruction: Add .github/CODEOWNERS containing `* @<owner>` and commit.

A finding that names no file points at `.github/CODEOWNERS`.
