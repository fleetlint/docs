# types/strict/kotlin

[types/strict](types--strict.md) does not apply to kotlin: nothing is checked for it.

## Why it does not apply

The compiler checks the types of every build; there is no separate type checker to make strict. Warnings the compiler can raise are covered by lint/strict.
