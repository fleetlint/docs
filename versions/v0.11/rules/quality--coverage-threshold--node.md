## Requirement

Jest `coverageThreshold`, Vitest `coverage.thresholds`, or c8/nyc with `check-coverage` is configured, or a stack-neutral floor applies.

## Why

A coverage number nobody enforces drifts down one "quick fix" at a time.

## Fix

Set `coverage.thresholds` in vitest.config (or `coverageThreshold` for Jest).

Agent instruction (from [quality/coverage-threshold](quality--coverage-threshold.md#fix)): Add a threshold to the cover recipe with the coverage tool of the stack profile (https://fleetlint.org/stacks/), or run diff-cover --fail-under on the coverage report.

A finding that names no file points at the first existing file of `vitest.config.*`, `vite.config.*` or `jest.config.*`, else `package.json`.
