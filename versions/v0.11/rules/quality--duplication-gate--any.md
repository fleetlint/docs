# quality/duplication-gate/any

Duplicated code is measured

The stack-neutral implementation of [quality/duplication-gate](quality--duplication-gate.md): it checks stacks without an implementation of their own and repositories where no stack is detected, and its satisfiers count for every stack.

## Requirement

jscpd, Simian or duplo runs in the task runner, the hooks or CI, or Sonar is configured (`sonar-project.properties`).

## Why

Near-duplicate implementations are how a fix lands in one copy and not the other; a detector makes the second copy visible at review time.

## Fix

This implementation has no fix of its own: see [quality/duplication-gate](quality--duplication-gate.md#fix).

A finding that names no file points at the task runner's file, or `Makefile` when there is none.
