# release/sbom/crate

[release/sbom](release--sbom.md) does not apply to the `crate` artifact: nothing is checked for it.

## Why it does not apply

crates.io holds the dependency graph and cargo-auditable embeds it in binaries; binaries built from the crate are checked as release files.
