# quality/coverage-threshold

A coverage floor is enforced

A capability: each stack checks it with its own tools, and every implementation that runs must pass. Implemented for [any](quality--coverage-threshold--any.md), [cpp](quality--coverage-threshold--cpp.md), [dotnet](quality--coverage-threshold--dotnet.md), [flutter](quality--coverage-threshold--flutter.md), [go](quality--coverage-threshold--go.md), [hugo](quality--coverage-threshold--hugo.md), [java](quality--coverage-threshold--java.md), [kotlin](quality--coverage-threshold--kotlin.md), [node](quality--coverage-threshold--node.md), [php](quality--coverage-threshold--php.md), [python](quality--coverage-threshold--python.md), [ruby](quality--coverage-threshold--ruby.md), [rust](quality--coverage-threshold--rust.md).

## Requirement

Tests fail below a coverage floor: the stack's coverage tool configured with a minimum, a threshold in the `cover` recipe, diff-cover `--fail-under`, or a codecov `target`. Comments and `echo` lines do not count. For a workspace member the repository's CI and configuration files in parent directories count as well.

## Why

A coverage number nobody enforces drifts down one "quick fix" at a time.

## Fix

Make the `cover` target fail below the floor with the stack's coverage tool, or run `diff-cover --fail-under=80` on its report (any stack).

Agent instruction: Add a threshold to the cover recipe with the coverage tool of the stack profile (https://fleetlint.org/stacks/), or run diff-cover --fail-under on the coverage report.
