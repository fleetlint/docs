# release/reproducible-build/crate

[release/reproducible-build](release--reproducible-build.md) does not apply to the `crate` artifact: nothing is checked for it.

## Why it does not apply

`cargo package` writes the sources with fixed timestamps; the crate of a commit is the same wherever it is packaged. Binaries built from it are checked as release files.
