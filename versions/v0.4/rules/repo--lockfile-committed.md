## Requirement

Each stack's dependency manager has its lockfile tracked in git next to the manifest, or, for a member of a workspace that keeps one lockfile for all members (npm, pnpm, yarn and bun workspaces, Cargo, uv and pub workspaces), at the workspace root; a manifest without dependencies needs none.

## Why

Builds are reproducible only when dependency versions are pinned in git.

## Fix

Generate the lockfile with the package manager and commit it; remove it from .gitignore.

Agent instruction: Run the package manager to produce the lockfile, remove any .gitignore entry for it, and commit it.

See: <https://fleetlint.org/baseline/#dependencies>
