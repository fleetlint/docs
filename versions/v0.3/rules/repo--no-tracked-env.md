## Requirement

Environment files that may hold credentials are never committed; templates with placeholder values (`.env.example`, `.sample`, `.template`, `.dist`) and encrypted files (`.sops`, `.enc`, `.age`, `.gpg`, `.asc`) are fine.

## Why

A tracked .env is the most common way credentials leak into history.

## Check

For each `item` in:

```cel
tracked().filter(f, f.matches('(^|/)\\.env(\\.[^/]*)?$')
                 && !f.matches('\\.(example|sample|template|dist|sops|enc|age|gpg|asc)$'))
```

```cel
false
```

## Fix

git rm --cached the .env file, add .env* to .gitignore, rotate any secret it contained.

Agent instruction: Untrack the .env file, add `.env` and `.env.*` (but not `.env.example`) to .gitignore, and tell the user which secrets must be rotated.

See: <https://fleetlint.org/baseline/#security>
