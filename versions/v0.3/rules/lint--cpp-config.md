## Requirement

A `.clang-tidy` with `WarningsAsErrors` and a `.clang-format` at the root; the build exports `compile_commands.json` so clang-tidy sees every translation unit.

## Why

Without a committed configuration every developer's editor runs different checks and the build runs none.

## Check

```cel
file(".clang-tidy") && file(".clang-format")
```

## Fix

Add .clang-tidy and .clang-format (`fleetlint fix --apply` writes both) and run clang-tidy in the lint target.
