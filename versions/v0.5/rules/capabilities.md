A capability states a requirement; each stack implements it with its own tools (`rules/<family>/<name>/<stack>.yaml`). `any` is the stack-neutral implementation: it checks stacks without their own and repositories where no stack is detected, and its satisfiers count for every stack. *Combine* says how the implementations add up: `all`, every implementation that runs must pass; `any`, one passing is enough (for what belongs to the repository, such as a release). `n/a` means the requirement does not apply to the stack (its page says why). A dash means no implementation yet; a report says so for a repository with that stack.
