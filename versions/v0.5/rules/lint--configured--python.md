## Requirement

A Python linter is configured in the project or a parent directory: ruff (`[tool.ruff]` in pyproject.toml, or ruff.toml), pylint or flake8. Another linter is added with `accept:`.

## Why

Untyped Python with default linting is where generated code hides most bugs.

## Fix

Add [tool.ruff] to pyproject.toml; `fleetlint fix --apply` appends it and a `dev` dependency group with ruff and mypy (then `uv sync`).

Agent instruction: Add [tool.ruff] with the profile's rule selection to pyproject.toml; ratchet existing violations with `ruff check --add-noqa`.

`fleetlint fix` can apply this rule's fix automatically (2 action(s)).
