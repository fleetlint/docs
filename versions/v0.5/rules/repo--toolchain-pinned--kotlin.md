Toolchain version is pinned

## Requirement

The JDK is pinned: a Gradle toolchain in the project's or a parent build (`jvmToolchain(n)`, `JavaLanguageVersion.of(n)`), `gradle-daemon-jvm.properties`, `.java-version`, `.sdkmanrc` with `java=`, or `.tool-versions`/mise naming java. The Gradle wrapper pins Gradle, not the JDK; the Kotlin version is pinned by the plugin version already.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Fix

Add `kotlin { jvmToolchain(21) }` to the build.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.
