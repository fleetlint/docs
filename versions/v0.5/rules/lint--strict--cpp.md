clang-tidy findings fail the build

## Requirement

The nearest `.clang-tidy` sets `WarningsAsErrors` (for example `'*'`), so a finding fails the build instead of scrolling past.

## Why

clang-tidy reports warnings and exits 0; without WarningsAsErrors its findings never stop a merge.

## Applies when

```cel
["", "../", "../../", "../../../"].exists(d, file(d + ".clang-tidy"))
```

## Check

```cel
[["", "../", "../../", "../../../"].map(d, d + ".clang-tidy").filter(f, file(f))] .exists(l, [yaml(l[0])].exists(y, y != null && "WarningsAsErrors" in y && y.WarningsAsErrors != null
  && string(y.WarningsAsErrors).trim() != "" && !string(y.WarningsAsErrors).trim().matches("^-\\*$")))
```

## Fix

Set `WarningsAsErrors: '*'` in .clang-tidy.

Agent instruction: Set WarningsAsErrors: '*' in .clang-tidy and fix the findings that now fail instead of narrowing the check list.
