# release/sbom/any

Releases publish an SBOM

The stack-neutral implementation of [release/sbom](release--sbom.md): it checks stacks without an implementation of their own and repositories where no stack is detected, and its satisfiers count for every stack.

## Requirement

The release pipeline produces the SBOM with a stack-neutral producer: GoReleaser `sboms:`, anchore/sbom-action or CycloneDX actions, syft, cyclonedx-* CLIs, trivy, cdxgen or Microsoft's sbom-tool, a Makefile `sbom` target the release workflow calls, or `docker/build-push-action` with `sbom: true`.

## Why

Consumers and scanners need to know what is inside an artifact; generating the SBOM in the pipeline ties it to the exact build.

## Capability applies when

```cel
release.mechanisms.exists(m, m != "git-cliff") && tagged_workflows().size() > 0 && !(!file(".goreleaser.yaml") && !file(".goreleaser.yml")
     && tagged_workflows().exists(w, steps(w).exists(s, s.uses.startsWith("pypa/gh-action-pypi-publish")
          || s.run.matches("\\b((npm|pnpm|yarn( npm)?) publish|twine upload|(uv|poetry|flit|hatch) publish|cargo publish|gem push|(dart|flutter) pub publish|dotnet nuget push)\\b")))
     && !tagged_workflows().exists(w, steps(w).exists(s,
          s.uses.matches("^(softprops/action-gh-release|ncipollo/release-action|actions/upload-release-asset|svenstaro/upload-release-action|goreleaser/goreleaser-action|docker/build-push-action)@")
          || s.run.matches("\\b(gh release (create|upload)|goreleaser|docker (buildx )?(build|push)|podman push|ko (build|publish)|release-cli|glab release|tea releases? create)\\b"))))
```

## Fix

Add an SBOM step to the tag-triggered release workflow (syft, SPDX JSON, one per artifact) or a `sboms:` section to .goreleaser.yaml, and upload the files with the release.

Agent instruction: In the tag-triggered release workflow add a step running syft on each artifact producing SPDX JSON files, and include them in the release upload step. Do not change other steps. If the repo uses GoReleaser, add a `sboms:` section instead.
