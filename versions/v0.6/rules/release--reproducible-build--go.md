# release/reproducible-build/go

Release builds are reproducible

## Requirement

Release binaries are built with `-trimpath`: in .goreleaser.yaml together with `mod_timestamp` (so archive timestamps come from the commit), or in a `go build` of the task runner or the release workflow; or SOURCE_DATE_EPOCH is set for the release build. Go embeds the module version and VCS revision itself.

## Why

When anyone can rebuild a release bit for bit from the tag, a tampered artifact or a compromised build machine shows up as a mismatch.

## Fix

Add `flags: [-trimpath]` and `mod_timestamp: "{{ .CommitTimestamp }}"` to the goreleaser builds.

Agent instruction: Add the stack's reproducibility settings to the release build and derive SOURCE_DATE_EPOCH from `git log -1 --format=%ct`; do not change what is built.
