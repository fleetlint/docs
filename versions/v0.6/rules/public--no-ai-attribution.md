# public/no-ai-attribution

Public history carries no AI attribution

| | |
|---|---|
| Severity | error |
| Tiers | all |
| Stacks | any |
| Scope | root |
| Kind | expr |
| Source | library v0.3.0 |
| Selected by | fleetlint-slop@v0.3.0 |

## Requirement

No commit in the recent history (`params.commits`, default 200) has an AI tool's address as author (`@anthropic.com`, the Copilot, Devin, Cursor, Codex, Jules and Claude bot accounts, `noreply@aider.chat`), a `Co-authored-by` trailer with such an address, or a "Generated with ..." footer. Names are not read: a person called Devin or Claude with their own address is not a finding.

## Why

For projects that do not want AI attribution in their history. Agent tooling adds the trailers and footers by default, so preventing them is a settings matter, while removing them later is a history rewrite.

## Applies when

```cel
repo.public && repo.has_git
```

## Check

For each `item` in:

```cel
commits(params.commits)
```

```cel
!(item.email.matches(r'(?i)^([^@\s]+@anthropic\.com|noreply@aider\.chat|cursoragent@cursor\.com|(\d+\+)?copilot@users\.noreply\.github\.com|(\d+\+)?(claude|copilot|copilot-swe-agent|devin-ai-integration|cursor|chatgpt-codex-connector|google-labs-jules|gemini-code-assist)\[bot\]@users\.noreply\.github\.com)$')
  || (item.body + "\n" + item.trailers).matches(r'(?im)^co-authored-by:[^<\n]*<([^@\s>]+@anthropic\.com|noreply@aider\.chat|cursoragent@cursor\.com|(\d+\+)?copilot@users\.noreply\.github\.com|(\d+\+)?(claude|copilot|copilot-swe-agent|devin-ai-integration|cursor|chatgpt-codex-connector|google-labs-jules|gemini-code-assist)\[bot\]@users\.noreply\.github\.com)>\s*$')
  || item.body.matches(r'(?im)^\s*(\x{1F916}\s*generated with\b|generated (with|by) \[?(claude code|claude|github copilot|copilot|chatgpt|cursor|codex|aider|gemini|devin)\b)'))
```

## Parameters

- `commits`: `200`

## Fix

Turn off commit attribution in the agent's settings; rewrite only unpushed history.

Agent instruction: Stop adding Co-Authored-By trailers and generated-with footers. Report the offending commits; rewriting pushed history needs the user's explicit decision.

See: <https://fleetlint.org/baseline/#public-repositories>, <https://fleetlint.org/slop/#commits-and-history>
