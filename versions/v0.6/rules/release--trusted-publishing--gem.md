# release/trusted-publishing/gem

Packages are published with trusted publishing

Implements [release/trusted-publishing](release--trusted-publishing.md) for the `gem` artifact: it runs when the release publishes one (see [artifacts](capabilities.md#artifacts)).

## Requirement

A GitHub or GitLab workflow that publishes to RubyGems (`gem push`, rubygems/release-gem) uses trusted publishing: `id-token: write` and no GEM_HOST_API_KEY or `--token` from secrets; on GitLab `id_tokens:`.

## Why

A registry token in CI secrets is valid for months and publishes from anywhere once leaked; an OIDC token is minted per run, scoped to this repository and workflow, and expires in minutes.

## Check

For each `item` in:

```cel
artifact_workflows("gem").filter(w, ci_kind(w) in ["github", "gitlab"])
```

```cel
ci_kind(item) == "gitlab"
  ? text(item).matches("(?m)^\\s*id_tokens:")
  : text(item).matches("id-token:\\s*write")
    && !grep(item, r'^\s*-?\s*(?:GEM_HOST_API_KEY)\s*:\s*["\x27]?\$\{\{\s*secrets\.(\w+)').exists(m, m.match.upperAscii() != "GITHUB_TOKEN")
    && !grep(item, r'--(?:token|api-key)[\s=]+["\x27]?\$\{\{\s*secrets\.(\w+)').exists(m, m.match.upperAscii() != "GITHUB_TOKEN")
```

## Fix

Register the workflow as a trusted publisher on rubygems.org, release with rubygems/release-gem from a job with `id-token: write`, and delete the API key secret.

Agent instruction: Grant `id-token: write` on the publishing job, remove the registry token from env/with (pypa/gh-action-pypi-publish without password, `npm publish` with npm 11.5.1 or newer, rust-lang/crates-io-auth-action for cargo, rubygems/release-gem for gems, NuGet/login for nuget.org, dart-lang/setup-dart for pub.dev; on GitLab add `id_tokens:` with the registry's audience), and tell the user to register the trusted publisher and delete the secret.

See: <https://fleetlint.org/baseline/#releases>, <https://fleetlint.org/baseline/#security>, <https://guides.rubygems.org/trusted-publishing/>
