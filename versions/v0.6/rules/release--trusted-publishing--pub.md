# release/trusted-publishing/pub

Packages are published with trusted publishing

Implements [release/trusted-publishing](release--trusted-publishing.md) for the `pub` artifact: it runs when the release publishes one (see [artifacts](capabilities.md#artifacts)).

## Requirement

A GitHub or GitLab workflow that publishes to pub.dev uses automated publishing with OIDC: `id-token: write` and no PUB_CREDENTIALS or PUB_TOKEN from secrets; on GitLab `id_tokens:`.

## Why

A registry token in CI secrets is valid for months and publishes from anywhere once leaked; an OIDC token is minted per run, scoped to this repository and workflow, and expires in minutes.

## Check

For each `item` in:

```cel
artifact_workflows("pub").filter(w, ci_kind(w) in ["github", "gitlab"])
```

```cel
ci_kind(item) == "gitlab"
  ? text(item).matches("(?m)^\\s*id_tokens:")
  : text(item).matches("id-token:\\s*write")
    && !grep(item, r'^\s*-?\s*(?:PUB_CREDENTIALS|PUB_TOKEN)\s*:\s*["\x27]?\$\{\{\s*secrets\.(\w+)').exists(m, m.match.upperAscii() != "GITHUB_TOKEN")
    && !grep(item, r'--(?:token|api-key)[\s=]+["\x27]?\$\{\{\s*secrets\.(\w+)').exists(m, m.match.upperAscii() != "GITHUB_TOKEN")
```

## Fix

Enable automated publishing from GitHub Actions on pub.dev for the package, publish from a job with `id-token: write` (dart-lang/setup-dart exchanges the token), and delete the credentials secret.

Agent instruction: Grant `id-token: write` on the publishing job, remove the registry token from env/with (pypa/gh-action-pypi-publish without password, `npm publish` with npm 11.5.1 or newer, rust-lang/crates-io-auth-action for cargo, rubygems/release-gem for gems, NuGet/login for nuget.org, dart-lang/setup-dart for pub.dev; on GitLab add `id_tokens:` with the registry's audience), and tell the user to register the trusted publisher and delete the secret.

See: <https://fleetlint.org/baseline/#releases>, <https://fleetlint.org/baseline/#security>, <https://dart.dev/tools/pub/automated-publishing>
