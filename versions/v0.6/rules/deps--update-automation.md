# deps/update-automation

Dependency updates are automated

## Requirement

Renovate (preferred, works on GitHub, GitLab, Gitea and Forgejo) or Dependabot keeps dependencies and pinned actions current: a Renovate config (`renovate.json`, `renovate.json5`, `.renovaterc*`, or one of those under `.github/`, `.gitea/`, `.forgejo/`, `.gitlab/`, or a `renovate` key in package.json) or `.github/dependabot.yml`. Tool versions count too: Renovate reads version-manager files (`mise.toml`, `.tool-versions`) directly, hook revisions once its pre-commit manager is enabled, and a version in a task runner file or a workflow when a `# renovate: datasource=... depName=...` comment sits above a `*_VERSION` variable.

## Why

Unpinned is unsafe and pinned-but-stale is unsafe too; only automation keeps both true.

## Check

```cel
exists("renovate.json") || exists("renovate.json5") || exists(".renovaterc") || exists(".renovaterc.json") || exists(".renovaterc.json5") || [".github", ".gitea", ".forgejo", ".gitlab"].exists(d, file(d + "/renovate.json") || file(d + "/renovate.json5")) || (file("package.json") && json("package.json") != null && "renovate" in json("package.json")) || file(".github/dependabot.yml") || file(".github/dependabot.yaml")
```

## Fix

Add renovate.json extending config:recommended with the pinned-actions preset; `fleetlint fix --apply` writes one with only the settings the repository's stacks need.

Agent instruction: Add renovate.json extending config:recommended and helpers:pinGitHubActionDigests; add gomodTidy only for a Go module and lockfile maintenance only where a package manager keeps a lockfile.

`fleetlint fix` can apply this rule's fix automatically (1 action(s)).
