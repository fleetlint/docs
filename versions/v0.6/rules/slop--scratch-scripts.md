## Requirement

No one-off scripts named `fix_*`, `debug-*`, `tmp_*`, `temp_*`, `scratch_*`, `try_*` or `quick_*` (such as `fix_imports.py`, `debug-auth.js`, `tmp_check.sh`) are tracked at the root. `test_*` files are tests, not scratch scripts.

## Why

They were written to answer one question once; nobody knows later whether they are safe to run or to delete.

## Check

For each `item` in:

```cel
tracked().filter(p, p.matches(r'^(fix|debug|temp|tmp|scratch|try|quick)[_-][^/]*\.(py|js|ts|sh|go|dart|kt|rs|rb|php)$'))
```

```cel
false
```

## Fix

Delete the script, or move it into a tools directory with a name that says what it does.

Agent instruction: Report the script; delete it only if nothing references it, otherwise move it under scripts/ with a descriptive name.
