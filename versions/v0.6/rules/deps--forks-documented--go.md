## Requirement

A go.mod `replace` pointing at another module (a local path such as `=> ../x` is a sibling module, not a fork) is documented in FORKS.md or a Forks section, or carries a `//` comment on the line.

## Why

A fork without a note outlives the reason for it; the next upgrade either drops the fix or keeps the fork forever.

## Applies when

```cel
grep("go.mod", r'=>\s*[a-z]').size() > 0
```

## Check

For each `item` in:

```cel
grep("go.mod", r'=>\s*[a-z]').filter(l, !l.text.contains("//"))
```

```cel
exists("FORKS.md") || exists("docs/FORKS.md") || exists("docs/forks.md") || grep("README.md", r'^#+ .*\b(forks?|vendored|patched|patches)\b').size() > 0 || grep("docs/**/*.md", r'^#+ .*\b(forks?|vendored|patched|patches)\b').size() > 0
```

## Fix

Add docs/FORKS.md listing each forked or patched dependency with upstream, base version, the change and why, or comment each line.

Agent instruction: Document each forked or patched dependency (upstream, base version, change, reason) in docs/FORKS.md; ask the user for the reason where the history does not say.
