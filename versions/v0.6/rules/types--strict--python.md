## Requirement

mypy runs with `strict = true` ([tool.mypy] in pyproject.toml, mypy.ini or setup.cfg) or pyright/basedpyright with `typeCheckingMode` strict (basedpyright also recommended or all; [tool.pyright], [tool.basedpyright] or pyrightconfig.json), in the project or a parent directory. Another type checker is added with `accept:`.

## Why

Untyped Python with default checking is where generated code hides most bugs; only strict mode refuses the implicit Any.

## Fix

Add [tool.mypy] with strict = true to pyproject.toml (`fleetlint fix --apply` appends it).
