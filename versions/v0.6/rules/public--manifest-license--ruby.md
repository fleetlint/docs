# public/manifest-license/ruby

Package manifest declares the license

## Requirement

Every gemspec sets `spec.license` (or `spec.licenses`) to an SPDX identifier.

## Why

Registries, SBOM tools and license checkers read the manifest, not the LICENSE file.

## Capability applies when

```cel
repo.public
```

## Check

```cel
glob("*.gemspec").all(f, text(f).matches(r'\.licenses?\s*='))
```

## Fix

Add `spec.license = "<SPDX id>"` to the gemspec.

Agent instruction: Set the manifest's license field to the SPDX identifier matching the LICENSE file; ask if the LICENSE text is not a recognised license.

See: <https://fleetlint.org/baseline/#public-repositories>, <https://fleetlint.org/stacks/#ruby>
