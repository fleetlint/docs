# deps/license-check/dotnet

Dependency licenses are checked against an allowlist

Implements [deps/license-check](deps--license-check.md) for dotnet.

## Requirement

A task-runner recipe or a CI step runs nuget-license (or its predecessor dotnet-project-licenses) with an allowed-licenses file (`-a`/`--allowed-license-types`), or a stack-neutral license checker.

## Why

A dependency under an incompatible license is found cheaply before it is merged and expensively after a release.

## Fix

Install nuget-license as a local dotnet tool and run `dotnet nuget-license -i x.sln -a allowed-licenses.json` in the `audit` target.

Agent instruction: Add the stack's license checker to the audit target with an allowlist compatible with the repository's own license; report dependencies outside it instead of widening the list.
