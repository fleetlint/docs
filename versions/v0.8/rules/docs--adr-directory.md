## Requirement

Significant decisions are recorded as Markdown ADRs (context, decision, consequences) in docs/adr, docs/decisions, docs/architecture/decisions, doc/adr (the adr-tools default) or adr/.

## Why

Without the why, the next person re-litigates every settled question.

```cel
["docs/adr", "docs/adrs", "docs/decisions", "docs/architecture/decisions", "doc/adr", "doc/architecture/decisions", "adr"].exists(d,
  exists(d + "/*.md"))
```

## Fix

Add docs/adr/0001-record-architecture-decisions.md and one ADR per existing major decision.
