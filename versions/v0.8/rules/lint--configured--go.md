## Requirement

A Go linter configuration is committed in the module or a parent directory: golangci-lint v2 (`version: "2"`), or staticcheck together with revive. Another linter setup is added with `accept:`.

## Why

Default linting misses the swallowed errors and oversized functions the baseline bans.

## Fix

Add .golangci.yml (version 2) from the Go stack profile; `fleetlint fix --apply` writes one.

Agent instruction: Create .golangci.yml with version: "2" and the linters listed in the Go stack profile, with a new-from-rev ratchet; convert a v1 file with `golangci-lint migrate`.
