## Requirement

Each stack pins its compiler or runtime to a version in a file the tools read, in the project's directory or a parent directory (for a workspace member, typically the repository root): the stack's version file, or `.tool-versions` / `mise.toml` naming the stack's tool with a version. A file that names another tool, or a moving alias like `lts` or `latest`, does not count.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Fix

Add the stack's version file with the version you build with today.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.
