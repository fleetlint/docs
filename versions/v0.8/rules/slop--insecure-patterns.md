No disabled TLS verification or similar shortcuts

## Requirement

No globally disabled certificate verification (a callback that accepts every certificate, `InsecureSkipVerify`, `verify=False`, `rejectUnauthorized: false`, `VERIFY_NONE`), bare `eval(`, `chmod 777` or wildcard CORS origin in non-test code. Method calls named `eval` (`model.eval()`, `redis.eval(`) and certificate callbacks that check the certificate are not findings.

## Why

Each one was added to make something work once and removes a protection for every user afterwards.

## Fix

Scope the exception to one host or one path with explicit opt-in, or remove it.

Agent instruction: Report each occurrence with what it disables; replace only when the secure equivalent is evident.
