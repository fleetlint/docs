## Requirement

Psalm's taint analysis (`psalm --taint-analysis`) runs in CI or the task runner; or a stack-neutral scanner (CodeQL, Semgrep, GitLab SAST, SonarQube).

## Why

SAST follows data from input to dangerous sinks across files, which per-file linters do not; on GitHub CodeQL is free for public repositories.

## Fix

Run `vendor/bin/psalm --taint-analysis` in the check workflow, or add a Semgrep step.

Agent instruction: Add a CodeQL workflow (github/codeql-action init/analyze, pinned) for the repository's languages, or on GitLab include `components/sast`; run it on pull requests and weekly.
