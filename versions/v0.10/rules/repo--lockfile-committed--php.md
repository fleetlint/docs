## Requirement

composer.lock is tracked when composer.json requires packages.

## Why

Builds are reproducible only when dependency versions are pinned in git.

## Check

```cel
"composer.lock" in tracked() || !text("composer.json").contains("\"require")
```

## Fix

Run `composer update --lock` (or `composer install`) and commit composer.lock.

Agent instruction: Run the package manager to produce the lockfile, remove any .gitignore entry for it, and commit it.

A finding of this rule points at `composer.lock`.
