## Requirement

Non-test code contains no `lorem ipsum`, `your-api-key`/`your_password`-style values, `changeme`, or string literals that are only an `example.com` address. Prose that mentions example.com, such as help text, is not a finding.

## Why

A placeholder that ships is a broken feature or a default credential.

## Check

For each `item` in:

```cel
codegrep("nontest", r'(?i)lorem ipsum|\byour[-_]?(api[-_]?key|token|secret|password)\b|\bchange[-_]?me\b|\breplace[-_]?me\b|[\x22\x27\x60](https?://)?([\w.+-]+@)?([\w-]+\.)*example\.(com|org|net)(:\d+)?(/[^\x22\x27\x60\s]*)?[\x22\x27\x60]')
```

```cel
false
```

## Fix

Read the value from configuration and fail at startup when it is missing.

Agent instruction: Replace with a configuration lookup validated at startup; ask where the real value comes from if that is unclear.
