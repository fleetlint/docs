## Requirement

A commit-msg hook checks every message: a pre-commit/prek hook at stage `commit-msg` or a known message linter (conventional-pre-commit, commitizen, commitlint, gitlint, cocogitto), or a command in lefthook's `commit-msg`. Which convention it enforces is not checked.

## Why

The changelog and version bump are generated from commit types; one bad message breaks both.

## Fix

Add the conventional-pre-commit hook with stages: [commit-msg] (lefthook: a commit-msg command running commitlint or cog verify).

Agent instruction: Add compilerla/conventional-pre-commit to .pre-commit-config.yaml with stages: [commit-msg] and the allowed types (feat, fix, refactor, perf, test, docs, build, ci, style, chore, revert).
