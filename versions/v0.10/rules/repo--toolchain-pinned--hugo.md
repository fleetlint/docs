# repo/toolchain-pinned/hugo

Toolchain version is pinned

## Requirement

The Hugo version is pinned: `.tool-versions`/mise or `devbox.json` naming hugo with a version, `HUGO_VERSION` in netlify.toml or vercel.json, or a CI file setting `HUGO_VERSION`, `hugo-version` or a versioned gohugoio/hugo image. In `devbox.json` the package needs a version (`hugo@0.152.2`); `@latest` does not count.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.


## Fix

Pin Hugo in mise.toml (`hugo-extended = "0.x.y"`) or set HUGO_VERSION in CI.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

A finding of this rule points at `mise.toml`.
