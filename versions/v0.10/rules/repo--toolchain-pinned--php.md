Toolchain version is pinned

## Requirement

`.php-version` names a version, composer.json's `config.platform.php` fixes the PHP version dependencies are resolved for, or `.tool-versions`/mise names php with a version.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Check

```cel
["", "../", "../../", "../../../"].exists(d, file(d + ".php-version") && scan(d + ".php-version", r'^\s*\d').size() > 0) || (file("composer.json") && text("composer.json").matches(r'"platform"\s*:\s*\{[^}]*"php"\s*:\s*"\d')) || ["", "../", "../../", "../../../"].exists(d, file(d + ".tool-versions") && scan(d + ".tool-versions", r'^\s*(php)\s+\S*\d').size() > 0) || ["", "../", "../../", "../../../"].exists(d, ["mise.toml", ".mise.toml", ".config/mise.toml", ".config/mise/config.toml", "mise/config.toml"].exists(n,
     file(d + n) && scan(d + n, r'^\s*"?(php)"?\s*=\s*[^#\n]*\d').size() > 0))
```

## Fix

Write the PHP version to .php-version (setup-php reads it).

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

A finding of this rule points at `.php-version`.
