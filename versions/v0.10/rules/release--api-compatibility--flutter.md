## Requirement

A Dart or Flutter package that is published (no `publish_to: none`) runs dart_apitool against the previous release.

## Why

A breaking change in a minor release is found by every user at once; the check finds it before the tag.

## Applies when

```cel
file("pubspec.yaml") && scan("pubspec.yaml", r'^publish_to:\s*\S*none').size() == 0 && exists("lib/*.dart")
```

## Fix

Run `dart_apitool diff --old pub://<package>/<previous> --new .` in the release workflow.

Agent instruction: Add the stack's API compatibility tool to the release workflow, comparing against the latest tag; on a breaking change bump the major version instead of silencing the tool.

A finding of this rule points at the file `tagged_workflows().size() > 0 ? tagged_workflows()[0] : ".github/workflows/release.yml"` yields.
