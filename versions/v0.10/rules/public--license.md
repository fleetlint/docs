# public/license

Public repository has a LICENSE

## Requirement

A public repository has a license file at its root: `LICENSE*`, `LICENCE*`, `UNLICENSE`, `COPYING*` (any case), or a REUSE `LICENSES/` directory. The manifest's SPDX identifier is checked by `public/manifest-license`.

## Why

Without a license, nobody may legally use the code.

## Applies when

```cel
repo.public
```

## Check

```cel
glob("*").exists(f, f.matches(r'(?i)^(un)?licen[cs]e([.-][^/]*)?$|^copying([.-][^/]*)?$')) || exists("LICENSES/*")
```

## Fix

Add LICENSE (MIT or Apache-2.0) with the current year and your name.

Agent instruction: Ask the user which license; add the LICENSE file and the SPDX identifier to the package manifest.

A finding of this rule points at `LICENSE`.
