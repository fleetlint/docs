## Requirement

The JDK is pinned: `.java-version`, `.sdkmanrc` with `java=`, a Gradle toolchain in the project's or a parent build (`JavaLanguageVersion.of(n)`, `jvmToolchain(n)`) or `gradle-daemon-jvm.properties`, the Maven enforcer's `requireJavaVersion`, or `.tool-versions`/mise naming java. The Gradle and Maven wrappers pin the build tool, not the JDK, and `maven.compiler.release` only sets the bytecode level; none of them counts.

## Why

Without a pin, every machine and every CI run builds with whatever compiler or runtime happens to be installed, and failures cannot be reproduced.

## Fix

Add a Gradle toolchain in the project's or a parent build (`java { toolchain { languageVersion = JavaLanguageVersion.of(21) } }`) or a .java-version file.

Agent instruction: Add the stack's toolchain pin set to the version currently installed; do not upgrade the toolchain in the same change.

A finding of this rule points at `.java-version`.
