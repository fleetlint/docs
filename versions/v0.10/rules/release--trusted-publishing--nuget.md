# release/trusted-publishing/nuget

Packages are published with trusted publishing

Implements [release/trusted-publishing](release--trusted-publishing.md) for the `nuget` artifact: it runs when the release publishes one (see [artifacts](capabilities.md#artifacts)).

## Requirement

A GitHub or GitLab workflow that pushes to nuget.org uses trusted publishing: `id-token: write`, the key from NuGet/login, and no NUGET_API_KEY or `--api-key` from secrets; on GitLab `id_tokens:`.

## Why

A registry token in CI secrets is valid for months and publishes from anywhere once leaked; an OIDC token is minted per run, scoped to this repository and workflow, and expires in minutes.

## Capability applies when

```cel
repo.artifacts.size() > 0
```

## Applies when

```cel
artifact.workflows.filter(w, ci_kind(w) in ["github", "gitlab"]).size() > 0
```

## Check

For each `item` in:

```cel
artifact.workflows.filter(w, ci_kind(w) in ["github", "gitlab"])
```

```cel
ci_kind(item) == "gitlab"
  ? text(item).matches("(?m)^\\s*id_tokens:")
  : text(item).matches("id-token:\\s*write")
    && !grep(item, r'^\s*-?\s*(?:NUGET_API_KEY|NUGET_AUTH_TOKEN)\s*:\s*["\x27]?\$\{\{\s*secrets\.(\w+)').exists(m, m.match.upperAscii() != "GITHUB_TOKEN")
    && !grep(item, r'--(?:token|api-key)[\s=]+["\x27]?\$\{\{\s*secrets\.(\w+)').exists(m, m.match.upperAscii() != "GITHUB_TOKEN")
```

## Fix

Register the workflow as a trusted publisher on nuget.org, take the key from `NuGet/login` in a job with `id-token: write`, and delete the NUGET_API_KEY secret.

Agent instruction: Grant `id-token: write` on the publishing job, remove the registry token from env/with (pypa/gh-action-pypi-publish without password, `npm publish` with npm 11.5.1 or newer, rust-lang/crates-io-auth-action for cargo, rubygems/release-gem for gems, NuGet/login for nuget.org, dart-lang/setup-dart for pub.dev; on GitLab add `id_tokens:` with the registry's audience), and tell the user to register the trusted publisher and delete the secret.
